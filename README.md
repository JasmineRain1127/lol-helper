# LOL Helper

一个用于《英雄联盟》大乱斗选角的 Windows 助手。它通过本机 LCU API 和 Riot Data Dragon 实现：

- 找到对局后自动接受；
- 读取大乱斗选角界面顶部的公共英雄池；
- 在客户端窗口外侧上方显示顺序一致的可点击英雄头像横条；
- 点击英雄后将其设为本局自动交换目标，再次点击可取消目标；
- 进入游戏或离开选角后自动隐藏，不抢占游戏画面。

## 界面与操作

助手平时在后台运行，不显示侧栏。横条显示时，左侧提供简短的选中状态与操作提示。进入大乱斗选角并检测到公共英雄池后，客户端窗口外侧上方会出现单行头像横条，不会覆盖客户端内部的英雄选择区域。

- 头像顺序与英雄联盟客户端顶部的公共英雄池一致；
- 每个头像使用客户端的固定公共池槽位坐标，并随客户端尺寸等比例缩放；
- 金色描边、勾选角标和英雄名称表示当前自动交换目标；点击后亮边动画反馈，取消时显示文字提示；
- 客户端聚焦时横条同步显示在前，切换到其他应用后随客户端退到后方，不全局置顶；
- 关闭 Windows 系统窗口动画时，助手保留静态提示并停用点击动画；
- 点击另一个头像可以直接更换目标；
- 横条会跟随客户端移动、缩放和最大化；
- 客户端最小化、公共英雄池为空、离开选角或进入游戏时，横条会隐藏；
- 头像悬浮不再显示英雄介绍、被动或 Q/W/E/R 技能信息。

程序启动后会常驻 Windows 系统托盘。右键托盘中的 LOL Helper 图标并选择“退出”即可完全关闭；双击托盘图标也可以直接退出。

> LCU 是 Riot 未正式支持的本地接口，版本更新可能改变字段或端点。本工具不会修改客户端、绕过服务器冷却，也不进行游戏内操作。使用前请自行确认并遵守 Riot 当前规则。

## 运行

要求 Windows 10/11 和 Python 3.11+，运行时无需安装第三方包。

```powershell
python main.py
```

程序启动时会自动请求 Windows 管理员权限。通过 UAC 确认后，管理员实例会继续启动，原普通权限进程会退出。

先启动英雄联盟客户端并登录，再启动本工具。自动接受、自动选角和自动交换默认开启。WeGame 可能以管理员权限启动客户端，因此助手也需要相同权限才能读取 LCU 启动参数。

配置保存在 `config/settings.json`，日志位于 `logs`。可在退出助手后修改 `auto_accept`、`auto_pick` 和 `auto_bench_swap`（`true` / `false`），重启后生效；启动时会保留这些开关。`poll_interval_ms` 支持 150–2000 毫秒，默认 350 毫秒；无效字段使用默认值。英雄头像及中文名称来自 Riot Data Dragon，并缓存到 `cache/ddragon`。本局目标只在当前选角会话内有效，离开选角或客户端连接断开后自动清空。

程序启动后会在后台预加载全部英雄头像。首次运行需要完成一次下载，之后直接使用本地缓存，避免交换英雄时因临时加载新头像导致横条消失。

## 打包

使用项目内的 PyInstaller 配置生成带管理员权限清单和 Windows 版本信息的单文件程序：

```powershell
python -m pip install -r requirements-dev.txt
python -m PyInstaller --clean --noconfirm LOL-Helper.spec
```

输出文件位于 `dist/LOL-Helper.exe`。打包版本会把配置、日志、诊断数据和 Data Dragon 头像缓存写入 `%LOCALAPPDATA%\LOL Helper`。

## 开发与测试

核心逻辑测试可在装有 Tkinter 的 Windows、macOS 或 Linux Python 环境运行；托盘、窗口跟随和真实 LCU 联动仍需在 Windows 客户端上验证。

```powershell
python -m unittest discover -s tests -v
```
